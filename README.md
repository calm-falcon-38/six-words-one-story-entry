One complete story in exactly six words:

> Every morning, she reintroduces herself. Wife.

## Run it

```sh
node main.ts
```

The program writes the story to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` when the grader names none). Node 22,
standard library only.
